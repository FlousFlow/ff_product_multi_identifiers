# Flous Flow Odoo 20 Product Identifiers

Production-ready Odoo 20 Community addons for assigning multiple ordinary
internal references and barcodes to the same product variant.

## Addons

- `ff_product_multi_identifiers`: base product identifier model, validation,
  product-form tags, search, security, Arabic translations, and documentation.
- `ff_pos_multi_identifiers`: optional POS loader, offline product search, and
  barcode fallback for active aliases.

Install the base addon first. Install the POS addon only when Point of Sale
alias lookup is required.

## Compatibility

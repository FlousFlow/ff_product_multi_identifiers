Multi Product Identifiers

Unlimited internal references and ordinary barcodes for one product variant

Key capabilities

  • Keep Odoo's native primary Reference and Barcode fields unchanged.
  • Add unlimited alternative identifiers to the same product variant.
  • Search products by primary values or aliases.
  • Use the same aliases in the optional POS integration.

Safe by design

  • Server-side uniqueness and conflict validation.
  • No changes to stock quantities, prices, taxes, or accounting.
  • Odoo 20 Community compatible.
  • Arabic translations included for user-facing labels and messages.
